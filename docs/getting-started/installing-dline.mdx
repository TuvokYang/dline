## IDE Extension

Use this if you want Dline inside your editor UI.

<Steps>
  <Step title="Open Extensions">
    Press `Ctrl/Cmd + Shift + X`.
  </Step>
  <Step title="Search for Dline">
    Type `Dline`.
  </Step>
  <Step title="Install">
    Click **Install** on the Dline extension.
  </Step>
  <Step title="Open Dline">
    Use the Dline activity bar icon, or run `Dline: Open In New Tab` from Command Palette.
  </Step>
  <Step title="Authorize with Dline">
    After installing the extension, complete provider setup in Dline settings.

    [Authorize with Dline](/getting-started/authorizing-with-dline)
  </Step>
</Steps>

<Note>
Windsurf and VSCodium use Open VSX. The install flow is the same.
</Note>
