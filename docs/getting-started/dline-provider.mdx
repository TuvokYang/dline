The **Dline provider** is the simplest way to get started with Dline.

Instead of managing separate API keys across multiple vendors, you sign in once and select from available models directly in Dline.

## Why use Dline provider

- **Fastest setup**: no manual API key copy/paste
- **One account**: sign in once with Google, GitHub, or email
- **Unified billing**: one balance across supported models
- **Free options**: look for models tagged **FREE** in the selector

## Setup

<Steps>
  <Step title="Open Dline Settings">
    Click the settings icon in the Dline panel.
  </Step>

  <Step title="Choose Provider">
    Set **API Provider** to **Dline**.
  </Step>

  <Step title="Sign In">
    Click **Sign In** and complete authentication in your browser.
  </Step>

  <Step title="Select a Model">
    Choose a model from the **Model** dropdown.
  </Step>

  <Step title="Verify">
    Send a test message. If Dline responds, setup is complete.
  </Step>
</Steps>

## Credits and usage
