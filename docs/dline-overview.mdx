Welcome to the Dline documentation. Whether you're just getting started or looking to unlock advanced capabilities, you'll find everything you need here.

## What is Dline?

Dline is an AI coding agent that lives in your editor. It can read and write files, run terminal commands, use a browser, and help you build features through natural conversation. Every action requires your explicit approval. You're always in control.
