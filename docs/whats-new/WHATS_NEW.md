# 新功能

Dline 侧边栏的 What's New 对话框展示本目录下英文版 `WHATS_NEW_en.md` 中最新的版本段落，本文件是与之对应的中文版本。Webview 构建时读取英文版，修改随下一次构建发布。完整变更见 [更新日志](../../CHANGELOG.md)。

## 0.11.2

- **对话轨迹条**：滚动聊天区时，右侧出现一列短条，每条对应一轮用户对话；悬停可预览该轮，点击即跳转过去，即使它不在已加载的范围内。
- **随时手动压缩**：`/compact` 每次压缩只显示一张卡片，任务运行中或对话框等待回复时也能使用，不会发出空消息。
- **统一的任务运行时与恢复**：任务状态由运行时事件与 reducer 驱动，中断、恢复与交接有明确状态机，历史任务重新打开不再依赖推测。

## 0.11.1

- **统一的任务运行时与恢复**：任务状态由运行时事件与 reducer 驱动，中断、恢复与交接有明确状态机，历史任务重新打开不再依赖推测。
- **语义化输入框**：用结构化 composer 取代纯文本输入，按来源切分提示词（提及、命令、粘贴、拖放），并能把不可读内容按字节原样交给模型。
- **任务性能优化**：聊天记录只校验并替换尾部，不再每次更新都读取并重写整段历史，耗时不再随任务长度增长。
- **MCP 工具按需加载**：设置「Load MCP Tools on Demand」（默认开启）不再把每个 MCP 工具的完整定义随每次请求发送，模型先从提示词中的目录选择工具，再用 `load_mcp` 取回参数 schema。
- **按钮交互优化**：发送、恢复、排队、取消共用一个按钮，任务运行时把草稿排入队列，悬停排队按钮 3 秒后切换为取消。

## 0.11.0

- **统一的任务运行时与恢复**：任务状态改由运行时事件与 reducer 驱动，中断、恢复与交接有明确状态机，历史任务重新打开不再依赖推测。
- **语义化输入框**：用结构化 composer 取代纯文本输入，按来源切分提示词（提及、命令、粘贴、拖放），并能把不可读内容按字节原样交给模型。
- **输入资源存储**：新增任务级输入资源仓库与类型化 RPC，图片与文件作为受管资源随任务持久化，而不是散落在消息文本里。
- **任务性能优化**：聊天记录改为只校验并替换尾部，不再每次更新都读取并重写整段历史，耗时不再随任务长度增长。
- **MCP 工具按需加载**：新增设置「Load MCP Tools on Demand」（默认开启），不再把每个 MCP 工具的完整定义随每次请求发送，模型先从提示词中的目录选择工具，再用 `load_mcp` 取回参数 schema。
- **按钮交互优化**：发送、恢复、排队、取消合并为一个按钮，任务运行时把草稿排入队列，悬停排队按钮 3 秒后切换为取消。

## 0.10.0

- **并行工具调用**：同一轮中无需人工审批的工具调用可以并发执行，最大并行数可配置。
- **更大的子代理批次**：`use_subagents` 单次最多运行 32 个子代理，每个子代理可分别指定 Agent、Profile 与超时。
- **Claude Code 与 Anthropic**：支持 OAuth 登录、托管 Web Search 与 Web Fetch，并以 Claude Opus 5.5 作为默认模型。
- **更丰富的附件**：PDF 作为原生文档完整发送，任意文本文件都可以粘贴或拖放到输入框。
- **可靠性**：历史任务重新打开更快，上下文压缩更稳健，TPM 只统计输出 Token。
