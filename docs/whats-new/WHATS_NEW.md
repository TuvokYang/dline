# 新功能

Dline 侧边栏的 What's New 对话框按界面语言展示本目录下中文或英文文件的最新版本段落。Webview 构建时读取两个版本，修改随下一次构建发布。完整变更见 [更新日志](../../CHANGELOG.md)。

## 0.14.0

- **中英文界面与自动回复语言**：界面默认跟随 VS Code，也可手动切换；模型回复可自动跟随你的语言。
- **子代理自动压缩**：开启 Auto Compact 后，子代理在内存中汇总上下文并继续工作。
- **子代理独立能力**：为具名代理分别选择 Rules、Skills、Workflows 与 MCP，审批限制不变。
- **DeepSeek 峰谷价格**：按当天显示，峰价先列、谷价随后，标题合并时段；周末和节假日只有全天谷价。
- **聊天导航更顺手**：悬停消息区或键盘聚焦即可使用轨迹和回顶／回底按钮，短窗口中也不再重叠。

## 0.13.2

- **中英文界面与自动回复语言**：界面默认跟随 VS Code，也可手动切换；模型回复可自动跟随你的语言。
- **商店图片加载修复**：扩展图标和演示动图使用直链，减少加载失败。

## 0.13.1

- **子代理自动压缩**：开启 Auto Compact 后，子代理在内存中汇总上下文并继续工作。
- **子代理能力独立选择**：为具名代理分别选择 Rules、Skills、Workflows 与 MCP，审批限制仍然生效。
- **DeepSeek 当日价格**：按北京时间显示当天窗口，周末和节假日为全天谷价，工作日显示峰价时段。
- **0.13 系列 OpenCode**：一个 Profile 使用付费文本模型，支持按量计费与 Go 套餐。
- **0.13 系列可靠保存**：Done 仅关闭设置；Profile 保存失败会报错并回读已保存值。

## 0.13.0

- **OpenCode 服务商**：一个 Profile 覆盖其付费文本模型，支持按量余额与 Go、Go Plus、Go Teams 订阅；同一模型可从 OpenAI Chat Completions、OpenAI Responses 或 Anthropic Messages 中选择接入方式。
- **Thinking 阅读更顺手**：支持基础 Markdown 排版，生成时跟随最新一行，上翻暂停跟随、回到底部恢复；点击正文不再误触发图片加载或文件打开。
- **设置与 Profile 保存更可靠**：Done 仅关闭页面，不再等待或重复保存；Profile 保存失败会显示错误并回读已保存值，编辑列表仍可继续使用。

## 0.12.2

- **按钮交互优化**：发送、恢复、排队、取消共用一个按钮，任务运行时把草稿排入队列，悬停排队按钮 3 秒后切换为取消。
- **中断与恢复更可靠**：任务被中断、关闭窗口或切换到历史任务后，恢复结果准确可预期，不再出现状态错乱或重复执行。
- **OpenCode 服务商**：一个 Profile 即可使用其全部付费文本模型，支持按量余额与 Go、Go Plus、Go Teams 订阅；同一模型可从 OpenAI Chat Completions、OpenAI Responses 或 Anthropic Messages 中选择接入方式，套餐决定价格与可用模型。

- **随时手动压缩**：`/compact` 每次压缩只显示一张卡片，任务运行中或对话框等待回复时也能使用，不会发出空消息。
- **中断与恢复更可靠**：任务被中断、关闭窗口或切换到历史任务后，恢复结果准确可预期，不再出现状态错乱或重复执行。

## 0.11.0

- **中断与恢复更可靠**：任务被中断、关闭窗口或切换到历史任务后，恢复结果准确可预期，不再出现状态错乱或重复执行。
- **输入更准确**：提及、斜杠命令、粘贴和拖放的内容按来源区分处理，不可读的文件也能按原样交给模型。

## 0.10.0

- **并行工具调用**：同一轮中无需人工审批的工具调用可以并发执行，最大并行数可配置。
- **更大的子代理批次**：`use_subagents` 单次最多运行 32 个子代理，每个子代理可分别指定 Agent、Profile 与超时。
- **Claude Code 与 Anthropic**：支持 OAuth 登录、托管 Web Search 与 Web Fetch，并以 Claude Opus 5.5 作为默认模型。
- **更丰富的附件**：PDF 作为原生文档完整发送，任意文本文件都可以粘贴或拖放到输入框。
- **可靠性**：历史任务重新打开更快，上下文压缩更稳健，TPM 只统计输出 Token。
