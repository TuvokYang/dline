Dline does not have a plugin system today. You cannot install plugins, and there is no public plugin manifest format or plugin API.

To extend Dline's behavior, use one of the mechanisms that are available now:

<CardGrid>
  <LinkCard title="Rules" description="Give Dline persistent project or personal instructions." href="/customization/rules/" />
  <LinkCard title="Skills" description="Package reusable task instructions that load on demand." href="/customization/skills/" />
  <LinkCard title="Hooks" description="Run scripts at points in the task lifecycle and around tool calls." href="/customization/hooks/" />
  <LinkCard title="MCP" description="Connect external tools, resources, and prompts through MCP servers." href="/mcp/mcp-overview/" />
</CardGrid>
