## Dline 是什么

Dline 是运行在编辑器中的 AI 编码智能体。它可以读写文件、执行终端命令、使用浏览器，并通过自然语言对话帮助你实现功能。

默认情况下，Dline 在读写文件、执行命令或调用外部工具前都会请求你的确认；你也可以在设置中为低风险操作开启自动审批。

## 安装 Dline

Dline 以 VS Code 扩展形式发布，需要 VS Code 1.134.0 或更高版本。获取 `.vsix` 文件后，通过 VS Code 的“从 VSIX 安装扩展”命令加载，或在终端中执行：

```bash
code --install-extension <vsix-file>
```
