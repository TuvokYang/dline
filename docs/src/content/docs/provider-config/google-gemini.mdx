Google Gemini 是 Google 的多模态模型系列，提供超长上下文窗口，适合编程、推理和文档分析。

**官网：** [ai.google.dev](https://ai.google.dev/)

## 获取 API Key

<Steps>

1. 访问 [Google AI Studio](https://aistudio.google.com/)，使用 Google 账号登录。

2. 打开 [aistudio.google.com/apikey](https://aistudio.google.com/apikey)。

3. 点击 **Create API Key**，选择或新建一个 Google Cloud 项目。

4. 立即复制并妥善保存 Key。

</Steps>

## 在 Dline 中配置

通用步骤见[授权与模型配置](/getting-started/authorizing-with-dline/)。

<Steps>

1. 点击 Dline 面板标题栏的 **Settings** 按钮。

2. 在 **API Provider** 中选择 **Google Gemini**。

3. 把 Key 粘贴到 **Gemini API Key** 输入框。

4. 在 **Model** 中选择模型。

</Steps>

默认请求地址为 `https://generativelanguage.googleapis.com`。需要走代理网关时，勾选 **Use custom base URL** 并填写地址。支持推理强度的模型会额外显示推理强度选项。
