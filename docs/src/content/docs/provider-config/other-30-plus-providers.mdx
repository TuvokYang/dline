This page covers the remaining providers that follow the same setup pattern. Use the table of contents on the right to jump to a provider.

## Shared setup flow

<Steps>

1. Click the **Settings** button in the Dline panel title bar.

2. Choose the provider under **Provider**.

3. Paste your API key or token into the matching credential field.

4. Select a model under **Model**.

</Steps>

See [Model configuration](/getting-started/authorizing-with-dline/) for the full flow.

## AIHubMix

An OpenAI-compatible model aggregator that gives you one API for multiple model backends.

**Website:** [aihubmix.com](https://aihubmix.com/)

1. Sign up for or sign in to an AIHubMix account.
2. Generate an API key in the dashboard.
3. In Dline, choose **AIHubMix** and paste the key.

## AskSage

An AI access platform for enterprise and government users, with compliance-oriented controls.

**Website:** [asksage.ai](https://www.asksage.ai/)

1. Sign in to AskSage and create API credentials.
2. Confirm that your workspace or organization has model access enabled.
3. In Dline, choose **AskSage** and enter the key.

## Baseten

Hosted model APIs and deployment infrastructure for production inference.

**Website:** [baseten.co](https://www.baseten.co/products/model-apis/)

1. Create a Baseten account and open the API keys page.
2. Generate an API key with the required permissions.
3. In Dline, choose **Baseten** and paste the key.

## Cerebras

**Website:** [cloud.cerebras.ai](https://cloud.cerebras.ai/)

1. Sign in to Cerebras Cloud.
2. Create or retrieve an API key.
3. In Dline, choose **Cerebras** and enter the key.

## GCP Vertex AI

**Website:** [cloud.google.com/vertex-ai](https://cloud.google.com/vertex-ai)

3. In Dline, choose **GCP Vertex AI**, fill in **Google Cloud Project ID**, and pick a region under **Google Cloud Region**.

## LiteLLM

A proxy gateway that gives you one interface to many model providers.

**Docs:** [docs.litellm.ai](https://docs.litellm.ai/docs/)

1. Start a LiteLLM proxy and note its address and API key.
2. In Dline, choose **LiteLLM**, enter the proxy address under **Base URL (optional)** (default `http://localhost:4000`), and enter the key under **API Key**.
3. Search for, select, or type a model ID under **Model**.

## VS Code Language Model API

Lets Dline use the built-in language models available in your VS Code installation. It appears as **GitHub Copilot** under **Provider**.

**Docs:** [VS Code Language Model API](https://code.visualstudio.com/api/extension-guides/language-model)

1. Make sure language models are available in your VS Code installation.
2. In Dline, choose **GitHub Copilot**. No API key or other configuration is needed.

3. Select a model under **Model**.
