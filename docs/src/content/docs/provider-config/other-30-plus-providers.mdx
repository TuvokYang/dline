本页列出配置流程相同的其他服务商。右侧目录可以直接跳转到对应服务商。

## 通用配置流程

<Steps>

1. 点击 Dline 面板标题栏的 **Settings** 按钮。

2. 在 **Provider** 中选择服务商。

3. 把 API Key 或 Token 粘贴到对应的凭证输入框。

4. 在 **Model** 中选择模型。

</Steps>

完整说明见[授权与模型配置](/getting-started/authorizing-with-dline/)。

## AIHubMix

兼容 OpenAI API 的模型聚合服务，用一套接口访问多个模型后端。

**官网：** [aihubmix.com](https://aihubmix.com/)

1. 注册或登录 AIHubMix 账号。
2. 在控制台生成 API Key。
3. 在 Dline 中选择 **AIHubMix** 并粘贴 Key。

## AskSage

面向企业和政府用户的 AI 访问平台，提供合规相关的管控能力。

**官网：** [asksage.ai](https://www.asksage.ai/)

1. 登录 AskSage 并创建 API 凭证。
2. 确认所在工作区或组织已开通模型访问。
3. 在 Dline 中选择 **AskSage** 并填写 Key。

## Baseten

**官网：** [baseten.co](https://www.baseten.co/products/model-apis/)

2. 生成具备所需权限的 API Key。
3. 在 Dline 中选择 **Baseten** 并粘贴 Key。

**官网：** [cloud.google.com/vertex-ai](https://cloud.google.com/vertex-ai)

## LiteLLM

用统一接口访问多家模型服务商的代理网关。

**文档：** [docs.litellm.ai](https://docs.litellm.ai/docs/)

1. 启动 LiteLLM 代理，记下代理地址和 API Key。
2. 在 Dline 中选择 **LiteLLM**，在 **Base URL (optional)** 中填写代理地址（默认 `http://localhost:4000`），在 **API Key** 中填写 Key。
3. 在 **Model** 中搜索、选择或直接输入模型 ID。

## VS Code Language Model API

让 Dline 使用当前 VS Code 中可用的内置语言模型。在 **Provider** 中显示为 **GitHub Copilot**。

**文档：** [VS Code Language Model API](https://code.visualstudio.com/api/extension-guides/language-model)

1. 确认当前 VS Code 中已有可用的语言模型。
2. 在 Dline 中选择 **GitHub Copilot**，无需填写 API Key 或其他配置。
