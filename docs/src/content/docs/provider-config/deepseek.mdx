## Get an API key

<Steps>

1. Go to the [DeepSeek Platform](https://platform.deepseek.com/) and sign up or sign in.

2. Open the [API keys](https://platform.deepseek.com/api_keys) page.

3. Click **Create new API key** and give the key a recognizable name, such as `Dline`.

4. Copy the key immediately and store it securely. You cannot view it again after closing the page.

</Steps>

## Configure Dline

See [Model configuration](/getting-started/authorizing-with-dline/) for the general flow.

<Steps>

1. Click the **Settings** button in the Dline panel title bar.

2. Set **Provider** to **DeepSeek**.

3. Paste the key into the **DeepSeek API Key** field.

4. Search for, select, or type a model ID under **Model**.

</Steps>

<Aside>
Models that support thinking show an **Enable Thinking** option. When it is on, choose the reasoning strength under **Thinking Level**.
</Aside>

## Read the price chart

The pricing panel follows the current day in Beijing time. On a day with both peak and off-peak pricing, it shows two groups:

- **Peak first.** The orange heading lists all peak intervals together, such as `09:00 – 12:00, 14:00 – 18:00`.
- **Off-peak second.** The green heading says **Other times** and shows the default rates for the remaining hours.

The timeline keeps each actual interval; grouping the prices does not merge intervals on the timeline or change the configured rates. Each heading uses the same color as its corresponding timeline segments. Identical rates appear once per group; if configured intervals have different rates, their individual times and prices remain visible inside the group.

On weekends and public holidays without peak pricing, only one off-peak group appears, covering `00:00 – 24:00`.
