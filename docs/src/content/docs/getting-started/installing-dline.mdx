Dline 以编辑器扩展形式发布，需要 VS Code 1.134.0 或更高版本。

## 从扩展市场安装

<Steps>

1. 按 `Ctrl+Shift+X`（macOS 为 `Cmd+Shift+X`）打开扩展视图。

2. 搜索 `Dline`。

3. 在 Dline 扩展上点击 **Install**。

4. 点击活动栏中的 Dline 图标打开 Dline 面板。

5. 在 Dline 设置中配置模型服务商，参见[授权与模型配置](/getting-started/authorizing-with-dline/)。

</Steps>

<Aside>
Windsurf、VSCodium 等编辑器使用 Open VSX 扩展仓库，安装流程相同。
</Aside>

## 从 VSIX 文件安装

获取 `.vsix` 文件后，在命令面板中运行 **Extensions: Install from VSIX...** 并选择该文件，或在终端中执行：

```bash
code --install-extension <vsix-file>
```
