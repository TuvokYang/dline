**官网：** [platform.deepseek.com](https://platform.deepseek.com/)

## 获取 API Key

<Steps>

1. 访问 [DeepSeek 开放平台](https://platform.deepseek.com/)，注册或登录账号。

2. 打开 [API keys](https://platform.deepseek.com/api_keys) 页面。

3. 点击 **Create new API key**，为 Key 起一个便于识别的名称，例如 `Dline`。

4. 立即复制并妥善保存 Key，页面关闭后将无法再次查看。

</Steps>

## 在 Dline 中配置

通用步骤见[模型配置](/zh-cn/getting-started/authorizing-with-dline/)。

<Steps>

1. 点击 Dline 面板标题栏的 **Settings** 按钮。

2. 在 **Provider** 中选择 **DeepSeek**。

3. 把 Key 粘贴到 **DeepSeek API Key** 输入框。

4. 在 **Model** 中搜索、选择或直接输入模型 ID。

</Steps>

<Aside>
支持思考模式的模型会显示 **Enable Thinking** 选项。开启后可以在 **Thinking Level** 中选择推理强度。
</Aside>

## 查看价格图

价格面板按北京时间当天展示。当天同时存在峰价和谷价时，详情聚合为两组：

- **峰价在前。** 橙色标题合并列出所有高峰时段，例如 `09:00 – 12:00, 14:00 – 18:00`。
- **谷价在后。** 绿色标题显示**其它时间**，列出剩余时段采用的默认价格。

上方时间条仍保留每个实际区间，价格聚合不会合并时间条区间或改变已配置的费率。标题文字与对应时间条使用相同颜色。同组相同价格只显示一次；若已配置的区间价格不同，各自的时间和价格仍保留在组内。

周末和法定节假日没有峰价时，只显示一组 `00:00 – 24:00` 的全天谷价。
