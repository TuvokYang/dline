**官网：** [openai.com](https://openai.com/)

Dline 提供两种使用 OpenAI 模型的方式：

- **OpenAI**：使用 OpenAI API Key，按 token 计费。
- **ChatGPT Subscription**：使用 ChatGPT 订阅账号登录，无需管理 API Key。

## OpenAI API Key

### 获取 API Key

<Steps>

1. 访问 [OpenAI Platform](https://platform.openai.com/)，注册或登录账号。

2. 打开 [API keys](https://platform.openai.com/api-keys) 页面。

3. 点击 **Create new secret key**，为 Key 起一个便于识别的名称，例如 `Dline`。

4. 立即复制并妥善保存 Key，OpenAI 不会再次显示它。

</Steps>

### 在 Dline 中配置

通用步骤见[模型配置](/zh-cn/getting-started/authorizing-with-dline/)。

<Steps>

1. 点击 Dline 面板标题栏的 **Settings** 按钮。

2. 在 **Provider** 中选择 **OpenAI**。

3. 把 Key 粘贴到 **OpenAI API Key** 输入框。

4. 在 **Model** 中搜索或选择模型。

</Steps>

### 自定义 Base URL

保持 **Use custom base URL** 未勾选时，请求发送到 OpenAI。勾选后，请求改为发送到你填写的其他地址，例如自建网关或其他兼容 OpenAI API 的服务。

<Steps>

1. 勾选 **Use custom base URL**，填入服务提供的地址，例如 `https://gateway.example.com/v1`。填写 API 地址本身，而不是服务商官网首页。

2. 把该服务签发的 Key 粘贴到 **OpenAI API Key** 输入框。

3. 在 **Model** 中选择模型，也可以选择服务返回但尚未内置在 Dline 中的 ID。列表没有提供所需 ID 时，勾选 **Use custom model ID** 并在 **Model ID** 中手动输入。

</Steps>

<Aside>
使用自定义 Base URL 时，Dline 只会把 Key 发送到你填写的地址。费用与价格由该服务决定，与 OpenAI 无关。
</Aside>

### 远程模型默认值与思考设置

选中模型和 Profile 都未声明提示缓存能力时，Dline 默认启用；明确的 `false` 仍表示关闭，缓存价格不决定这一能力。

在 OpenAI API Key 和兼容服务的 Profile 中，没有推理声明的模型默认勾选“启用思考”。兼容等级为 `none`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`、`ultra`，请按端点支持情况选择。不选择等级时使用端点默认值；选中等级后保存到 Profile。Chat Completions 发送所选原值，Responses 将 `ultra` 编码为 `max`。如果端点拒绝该等级，请改选它支持的等级。

模型的明确声明决定预算模式、等级列表和默认值。明确不支持推理时隐藏思考控件；空等级列表显示勾选项，隐藏等级选择器。用户关闭思考后保持关闭，模型声明不允许关闭思考的情况除外。

新发现的 GPT 次版本可以从相同主版本、完全相同变体的最近旧目录条目继承缓存和思考声明。例如，`gpt-6.2-astra` 可以使用 `gpt-6-astra` 已声明的缓存能力和推理等级，但不复制价格、上下文或输出限制、图像能力、托管工具或 API 格式。目标模型自身声明和用户显式能力配置优先。

ChatGPT Subscription 在自身目录内使用相同的限定继承，不借用 API Key 目录的能力。没有可用思考声明时，也提供上述默认启用的兼容选项；明确模型声明优先，不选择等级时保持未指定。

### 未声明的托管网页搜索

在 **模型配置** 中，未声明托管工具的模型可以勾选 **使用托管网页搜索** 进行兼容性尝试。初始不勾选，选择保存在当前 Profile 的当前模型中；切换模型或 Provider 后清除该选择。模型明确声明空工具列表时仍不可用。

使用托管搜索需要选择 **Responses** 并启用原生工具调用；全局网页工具设置、Profile 路由模式和关闭开关仍然生效。如果端点拒绝托管搜索，可以取消勾选并改用本地网页搜索。

### 自定义价格

启用自定义 Base URL 后，**固定费率** 只编辑一组价格，不显示 **添加定价分档**。需要添加分档时，先选择 **按上下文大小**，或在 **按时段** 中选择分档费率。能力勾选与下方能力说明均读取当前模型及 Profile 显式配置。

### Azure OpenAI

- 在 **Use custom base URL** 中填写 Azure OpenAI 资源的地址。
- 需要固定 API 版本时，勾选 **Set Azure API version** 并填写版本，默认 `2024-10-01-preview`。
- 勾选 **Use Azure Identity Authentication** 可以复用现有的 Azure 托管身份认证。它不会主动发起登录，只会复用已有的认证状态（例如 `az login`）。

## ChatGPT 订阅

<Steps>

1. 打开 Dline 设置，在 **Provider** 中选择 **ChatGPT Subscription**。

2. 点击 **Sign in**。Dline 会打开 **Sign in to ChatGPT** 对话框并启动系统浏览器。

3. 在浏览器中完成授权。浏览器自动回到 Dline 后，对话框关闭，状态显示 **Signed in**。

4. 在 **Model** 中选择模型。可用模型取决于你的 ChatGPT 套餐。

</Steps>

### 浏览器无法自动返回时

1. 保持 **Sign in to ChatGPT** 对话框打开，不要取消。
2. 从浏览器地址栏复制授权完成后的**完整回调 URL**。
3. 粘贴到对话框中的 **Full callback URL** 输入框，然后点击 **Finish sign-in**。

浏览器没有自动打开时，可以复制对话框中的登录 URL，手动粘贴到浏览器。登录超时后点击 **Try again** 重新开始。

### 导入已有凭据

正常登录无法完成时，可以在对话框中展开 **Advanced: import OAuth credential JSON**，粘贴完整的 OAuth 凭据 JSON，然后点击 **Import credential**。凭据会写入该 Profile 自己的密钥文件。

### 多个 Profile

每个 API Profile 独立保存自己的 ChatGPT 凭据。一个 Profile 登录、退出或删除，不会影响其他 Profile；需要使用多个 Profile 时，分别为每个 Profile 登录一次。

<Aside type="caution">
不要把 Dline 数据目录下的 `secrets/` 文件提交到版本控制、附到工单或发送给他人。更换账号时请使用 **Sign in again**，不要手动编辑凭据文件。
</Aside>
