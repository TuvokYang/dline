本隐私政策说明 Dline 维护者如何通过 Dline VS Code 扩展以及扩展所访问的 Dline 运营服务处理信息。Dline 是独立维护的社区软件，不是 Cline 官方版本，也不隶属于 Cline Bot Inc.，未获得其背书。

## 1. 责任主体

本政策所述 Dline 特定处理活动由 Dline 维护者负责，Marketplace 发布者身份为 `tuvokyang`。

隐私或安全请求请联系 `security@dline.cc`。请勿在普通邮件或公开 Issue 中附带 API Key、访问令牌、源代码、私有提示词或其他秘密信息。

你选择使用的模型服务商、MCP 服务器、网站、图像服务、身份服务及其他集成，会按照各自的条款和隐私政策对收到的信息承担责任。

## 2. 适用范围

本政策适用于：

- Dline VS Code 扩展；
- 扩展访问的 `dline.cc` 下 Dline 运营的文档、支持和遥测服务；
- 你明确选择向 Dline 提供的诊断或支持信息。

本政策不会替代你自行选择的模型服务商、MCP 服务器、浏览目标、代码托管平台、图像服务商或其他第三方服务的政策。

## 3. Dline 的基本处理原则

- Dline 默认把设置、凭据、任务历史、消息、活动、检查点和恢复状态保存在本机。
- 只有任务使用你配置的 Profile 发起模型请求时，Dline 才会向对应模型服务商发送任务内容。
- 外部工具只会在你批准操作或启用匹配的自动批准规则后，收到执行该操作所需的数据。
- 使用情况报告和错误报告是两个独立开关。当前版本两者默认开启，同时受 VS Code 遥测设置约束，并可分别关闭。
- Dline 不出售个人信息，也不把任务内容用于广告。
- 普通远程使用情况或错误报告不会有意包含提示词、源代码、文件内容、命令、终端输出或用户身份。

## 4. 保存在你设备上的信息

Dline 可能在本机保存：

- API Profile、服务商端点、模型选择和功能设置；
- API Key、OAuth token、服务商凭据和 MCP secret，并存入专用凭据存储；
- 任务消息、所选附件、工具结果、活动、用量记录和恢复快照；
- 工作区设置、能力开关、规则、技能、工作流、hook 和 MCP 描述文件；
- 命令日志、诊断记录、浏览器资源、图片预览和临时输入资源；
- Git 检查点元数据和任务历史索引；
- 已启用报告通道使用的假名化安装或设备标识。

除非某项功能按下文说明把数据发送给已配置服务，或你自行导出并分享，本地信息会留在设备上。本地数据会保留到你删除相应任务、凭据、设置、缓存、诊断数据或 Dline 存储目录，或者扩展依据已公开的容量与时间上限进行清理。

卸载扩展不一定会删除 VS Code 扩展安装目录之外的数据。请先备份需要保留的内容，再使用 Dline 删除功能或移除 Dline 的 data、home 和 documents 根目录。

## 5. 模型服务商请求

当你发送任务，或 Dline 继续执行已批准的任务时，Dline 会向该任务 API Profile 选定的模型服务商发送生成响应所需的信息。根据任务和你的选择，可能包括：

- 你的提示词和后续反馈；
- 系统指令、已启用规则、技能、工作流和工具定义；
- 你选择的源代码、文件、图片、文档、诊断或工作区上下文；
- 之前的对话消息和模型回复；
- 已批准的工具结果、命令输出、浏览结果、MCP 结果和生成的摘要；
- 路由请求所需的服务商和模型配置。

模型服务商决定如何处理、保留和使用这些信息。添加凭据前，请阅读服务商隐私政策和数据使用设置。Dline 无法删除第三方服务商已经收到的数据。

## 6. 外部工具与服务

只有相关能力对任务可用且满足对应审批策略时，Dline 才能调用外部服务。

### MCP 服务器

MCP 服务器可能收到工具参数、资源标识、提示内容以及该服务器所需的认证信息。全局或工作区 MCP 配置可能由你或项目其他贡献者创建。启用前请核对服务器运营者、源码、权限和隐私条款。

### Web 搜索、页面抓取与浏览器自动化

搜索服务和目标网站会收到正常网络信息，例如查询词或 URL、IP 地址、User-Agent、所选浏览器上下文中已有的 Cookie，以及你批准提交的表单数据或页面操作。浏览器自动化可能暴露受控页面中显示或输入的信息。

### 命令、文件与源代码管理

命令在你的机器上运行，并可能访问命令中指定的任意服务。文件工具只能在获准范围内读取或修改。检查点使用本地 Git 仓库，可能在本地检查点对象中记录路径、哈希和文件内容。除非你另行批准会执行远程写入的命令或工作流，Dline 不会把检查点推送到远程仓库。

### 图片与文档

图片生成服务会收到你批准的提示词、参考图或遮罩。模型服务商可能收到你附加的图片、PDF、文档、提取文本，或已批准工具返回的相关内容。

## 7. 使用情况报告

当前版本默认开启 **Allow usage reporting**，你可以在 **Settings → About** 中关闭。VS Code 的 `telemetry.telemetryLevel` 和组织策略可以进一步限制投递，但不能在你关闭后重新开启该通道。

启用时，Dline 可以向 `otel.dline.cc` 发送有界的运行统计和维度，例如：

- Dline 版本、发布通道、操作系统和编辑器类型；
- 服务商、模型、API 格式和任务用途分类；
- 请求结果、耗时、重试、吞吐量和 token/cache/cost 计数；
- 汇总后的工具、MCP、任务、子代理和功能使用计数；
- 本地丢弃计数和协议健康信息。

普通使用情况请求按设计不包含提示词、模型回复、源代码、文件内容、文件路径、命令、终端输出、任务或工作区身份、账号身份、API Key 或访问令牌。如果你把机密信息写进自定义服务商或模型 ID，该 ID 仍可能泄露信息。请勿把账号编号、客户名称、仓库名、secret 或其他敏感值用作自定义 ID。

关闭使用情况报告会停止该远程通道的新采集、中止投递，并按当前客户端实现删除尚未发送的使用记录和本地 usage access token；已经被服务端接收的数据不会因此删除。

当前 wire 字段、限制、本地队列、重试和删除行为见[遥测、隐私与 Issue 诊断](/zh-cn/troubleshooting/telemetry/)。

## 8. 错误与运行时报告

当前版本默认开启 **Allow error reporting**，可在 **Settings → About** 中独立关闭。宿主和组织遥测设置可以进一步限制投递。

启用时，Dline 可以向 `otel.dline.cc` 发送白名单内的失败与运行时健康记录，包括事件类型、严重度、安全错误码或指纹、服务商/模型分类、阶段、是否可重试、耗时和有界性能测量。

普通远程错误报告按设计不包含自由文本错误消息、堆栈、提示词、模型回复、源代码、文件内容、路径、URL、命令、终端输出、任务或工作区身份、账号身份、API Key 或访问令牌。

关闭错误报告会停止新的远程诊断、中止投递，并按当前客户端实现删除尚未发送的诊断和本地 diagnostics access token；已经被服务端接收的数据不会因此删除。

## 9. 诊断包与支持报告

只有你主动请求导出时，Dline 才会创建诊断包。诊断包写到本机，不会自动上传。分享前请先检查内容。

Bug 报告流程会先显示审批预览，再打开预填的 Issue 或授权页面。只有你检查目标表单并提交后，信息才会进入公开 Issue。可用时，临时高密度诊断还需要单独的 Issue 专属授权，普通使用情况或错误报告同意不会自动授予该权限。

你提交到支持渠道的信息会作为该请求的一部分保留；公开 Issue 中的信息对所有人可见。提交前请移除 secret 和机密项目内容。

## 10. 处理目的与法律基础

Dline 处理信息用于：

- 提供扩展、已配置集成和你请求的支持；
- 保护本地凭据和服务访问；
- 保存任务状态和恢复中断工作；
- 执行权限、阻止滥用并保护服务安全；
- 诊断失败并改进兼容性、可靠性和功能设计；
- 在报告开启时测量汇总使用情况；
- 履行法律义务并响应有效法律要求。

根据适用法律和具体功能，处理可能基于你要求提供服务、你的同意或设置选择、Dline 对安全与可靠性的合法利益，或法律义务。你可以随时通过 Dline 设置撤回可选报告同意。

## 11. 共享与披露

Dline 可能向以下接收方披露信息：

- 你配置的模型服务商和集成运营者；
- Dline 服务使用的基础设施、托管、认证、支付、邮件、日志和安全供应商；
- 为解决请求或保护服务而确有访问需要的维护者和支持人员；
- 法律要求或为保护用户、Dline 或公众所必需的机关或其他主体；
- Dline 服务责任发生转移时的继受方，但仍受适用通知和法律约束。

Dline 不出售个人信息，不向数据经纪商提供任务内容，也不将其用于第三方广告。

## 12. 保留期限

Dline 遵循数据最小化原则，只在实现所述目的所需期间保留信息：

- 本地任务、配置、凭据和缓存数据会保留到你删除，或适用已公开的本地清理上限；
- 尚未发送的使用情况和诊断数据受客户端容量限制，并在相应报告开关关闭时删除；
- 服务端已接收的使用情况和诊断记录只用于服务运行、安全、汇总分析与排错，随后依据服务保留计划删除或不可逆聚合；
- 支持和安全报告在处理期间以及结案后的合理期限内保留，用于防止回归并记录处置结果。

在发布 Marketplace 正式版本前，Dline 必须为每个 Dline 运营的远程服务公开并执行具体服务端保留计划。如果公开服务文档尚未给出某类数据的最长保留期，请在开启该可选类别前联系 `security@dline.cc`。

## 13. 安全措施

Dline 使用分域存储所有者、平台支持时的 owner-only 凭据文件、原子本地写入、有界队列、Dline 远程服务的加密传输、取消机制和隐私白名单。任何系统都无法保证绝对安全。

请保护设备、VS Code Profile、服务商账号、仓库、MCP 配置和 API 凭据。发现疑似漏洞时，请按 [Dline 安全政策](https://github.com/TuvokYang/Dline/security/policy)私下报告。

## 14. 你的选择与权利

你可以：

- 分别关闭使用情况报告和错误报告；
- 降低或关闭 VS Code 遥测；
- 删除服务商凭据、Profile、MCP 服务器、任务、附件和本地 Dline 数据；
- 拒绝工具请求或移除自动批准规则；
- 在可用时选择本地模型或本地集成；
- 分享前检查诊断包或 Issue 表单；
- 在适用法律赋予相应权利时，请求访问、更正、删除、限制、反对、可携带或撤回同意。

隐私请求发送到 `security@dline.cc`。Dline 可能需要先核验身份和请求范围。对于只由第三方服务商控制的数据，Dline 无法代为完成请求，请直接联系对应服务商。

## 15. 跨境处理

Dline 维护者和服务供应商可能在你所在国家或地区以外处理信息。适用法律要求时，Dline 会采用相应传输机制以及合同或技术保障。你选择的模型服务商或集成可能依据其政策使用不同地点和保障措施。

## 16. 未成年人

Dline 是开发者工具，不面向未成年人。如果你未达到适用法律或相关服务条款要求的最低年龄，请勿使用 Dline 运营的服务。

## 17. 政策变更

重大变更会更新本页顶部日期，并通过 Dline 发布说明或其他适当方式说明。修改本政策不会静默开启你已经关闭的报告开关。
