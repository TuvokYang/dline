轨迹导航是聊天右侧的一列短横线，用于在长任务中定位历史用户消息。

## 查看轨迹

1. 打开一个已有对话的任务，把鼠标移到聊天消息区，无须先滚动。
2. 右侧出现轨迹栏；每条短横线对应一轮用户消息，标记按 **Attempt** 分组。
3. 把鼠标悬停在标记上，预览该轮消息；点击标记，跳到对应的用户消息。

当前阅读位置所在的回合会高亮。鼠标悬停在消息区，或用键盘操作浮动控件时，轨迹栏与当前可用的回顶／回底按钮会保持显示；鼠标移出且控件没有键盘焦点后淡出。也可以用键盘聚焦标记，再按 `Enter` 或空格跳转。

轨迹栏为下方按钮留出空间；消息区较矮时，按钮并排显示。长轨迹在栏内滚动，每轮消息的标记仍可访问。

## 预览中有什么

- **Attempt / Turn**：所在分组与回合编号；
- 该轮用户消息的预览；
- 已记录的模型请求轮数；
- 工具名称及对应调用次数。
