轨迹导航是聊天右侧的一列短横线，用于在长任务中定位历史用户消息。

## 查看轨迹

1. 打开一个已有对话的任务，滚动聊天记录。
2. 右侧出现轨迹栏；每条短横线对应一轮用户消息，标记按 **Attempt** 分组。
3. 把鼠标悬停在标记上，预览该轮消息；点击标记，跳到对应的用户消息。

当前阅读位置所在的回合会高亮。停止滚动后轨迹栏会淡出；鼠标位于栏内，或键盘焦点仍在其中时，会保持显示。也可以用键盘聚焦标记，再按 `Enter` 或空格跳转。

## 预览中有什么

- **Attempt / Turn**：所在分组与回合编号；
- 该轮用户消息的预览；
- 已记录的模型请求轮数；
- 工具名称及对应调用次数。
