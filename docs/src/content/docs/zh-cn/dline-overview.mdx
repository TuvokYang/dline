**功能完备的多任务自动化编程代理**

Dline 支持在同一工作区内并行开展多个编程与代码审查任务，用于制定架构与编码任务、编写代码、开展代码审查与问题修复，以及维护项目文档。每个任务在自己的上下文中衔接规划、实施与验证，让多个开发目标可以同时推进。

## 核心能力

- **[多模型配置](/zh-cn/getting-started/authorizing-with-dline/)**：接入云端服务或本地模型，为每个任务的 **Act**（执行）、**Plan**（规划）和 **Subagent**（子代理）分别选择模型，不必让所有工作共用一个模型。
- **[多任务并行执行](/zh-cn/core-workflows/task-management/)**：同时推进功能开发、缺陷修复、代码重构、界面调试和文档维护等任务，各自保留对话、进度与执行记录。任务内还可委派多个子代理并行调查不同模块，再汇总结果继续工作。
- **[多层级配置](/zh-cn/customization/capability-scopes/)**：按全局、项目和任务分别管理规则、技能、工作流、子代理和 MCP 的启用状态。为子代理配置职责、模型、工具和技能，为项目配置终端环境与命令执行前后的操作。
- **[长任务续接](/zh-cn/features/auto-compact/)**：通过自动压缩管理模型上下文，原始对话与运行记录保留在本机；中断后可以重新打开任务、检查进展并继续。
- **[持久化任务记录](/zh-cn/core-workflows/task-management/#task-records)**：自动保存对话、执行记录和任务进度，关闭面板或重启编辑器后可从历史中重新打开并继续。
- **[丰富的工具能力](/zh-cn/tools-reference/all-dline-tools/)**：搜索网络资料、获取网页正文，通过浏览器与截图检查页面和交互，也可使用配置的图像服务生成图片并提供参考图。
- **[多层级 MCP 扩展](/zh-cn/mcp/mcp-overview/)**：按全局或项目配置 MCP 服务，调用外部工具并获取资源，支持远程服务的 OAuth 授权。授权 Key 等私有内容可单独保存在本机，通过变量引用供连接使用。
- **[细分的操作授权](/zh-cn/features/auto-approve/)**：分别配置项目内外的读写、命令、浏览器、Web 联网、MCP 和图片生成等操作的批准方式。命令区分安全命令与全部命令，授权设置全局生效。
- **[持久化的检查点](/zh-cn/core-workflows/checkpoints/)**：利用 Git 构建文件检查点，利用持久化对话存储构建对话检查点，可将文件和对话回滚至已有检查点。

## 编程任务

- **制定架构与编码任务**：梳理需求与项目现状，设计架构和接口，拆解编码任务、实施顺序与验证步骤。
- **代码编写**：实现功能、重构代码、调整界面与配置，补充测试并验证结果。
- **代码审查与问题修复**：审查代码逻辑、结构与边界情况，结合报错和日志定位问题，完成修复与回归验证。
- **文档维护**：根据项目实际情况，编写或更新架构设计、项目说明、使用指南和变更记录等文档。
