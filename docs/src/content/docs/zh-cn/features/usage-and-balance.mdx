对于能返回账户用量的服务商，Dline 会在输入工具栏中显示一个用量胶囊，展示当前模式所用 Profile 背后的账户情况。

## 支持的服务商

| 服务商 | 显示内容 | 读取方式 |
|---|---|---|
| **OpenAI Codex**（ChatGPT 登录） | `5 hour`、`7 day` 等额度窗口；账户有重置卡时一并显示 | 每个 Profile 读取一次，之后通过 **Refresh** 手动刷新 |
| **Claude Code**（Claude 登录） | `5 hour`、`This week` 以及按模型区分的周额度 | 每个 Profile 读取一次，之后通过 **Refresh** 手动刷新 |
| **DeepSeek** | 账户剩余余额 | Dline 视图可见时每 60 秒刷新一次 |

订阅用量接口与对话共用同一个账户额度，因此 Codex 和 Claude Code 不做定时轮询。余额轮询在 Dline 视图隐藏时暂停，重新可见后恢复。

OpenRouter 的密钥余额显示在 Profile 编辑器的 API Key 输入框旁，而不在工具栏中。

## 读懂用量胶囊

- 订阅账户显示某一个窗口的剩余百分比，例如 `5h: 72%`。5 小时窗口在使用中时优先显示；如果其他窗口已经耗尽，则改为显示那个窗口，因为它才是阻止请求的原因。
- 余额账户显示服务商币种的余额。
- 无法读取数据的窗口会被跳过，不会显示成 `0%`。
- 当前 Profile 没有用量数据，或面板过窄时，胶囊不会显示。

悬停胶囊可以预览所有窗口的剩余百分比、进度条和重置时间。点击胶囊打开 **Usage** 面板，其中有 **Refresh** 按钮；Codex 账户还会列出重置卡。

## 重置卡

OpenAI Codex 账户有额度重置卡时，**Usage** 面板会列出每张卡及其过期时间。选择一张卡并确认后，符合条件的窗口会被重置，面板中会显示结果，例如哪些窗口已重置。

<Aside>
用量与 Profile 绑定。切换 Profile 或模式时，会清除上一次的读数并加载新 Profile 的用量。
</Aside>
