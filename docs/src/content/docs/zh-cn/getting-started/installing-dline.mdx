Dline 以编辑器扩展形式发布，需要 VS Code 1.134.0 或更高版本。

## 从扩展市场安装

### Open VSX

在使用 Open VSX 的编辑器（如 Windsurf、VSCodium）中：

<Steps>

1. 按 `Ctrl+Shift+X`（macOS 为 `Cmd+Shift+X`）打开扩展视图。

2. 搜索 `Dline`，确认发布者为 `tuvokyang`。

3. 在 **Dline** 扩展上点击 **Install**。

</Steps>

### VS Code Marketplace

在 VS Code 中：

<Steps>

1. 按 `Ctrl+Shift+X`（macOS 为 `Cmd+Shift+X`）打开扩展视图。

2. 搜索 `Dline (Stable)`，确认发布者为 `tuvokyangdline`。

3. 在 **Dline (Stable)** 扩展上点击 **Install**。

</Steps>

安装完成后，点击活动栏中的 Dline 图标打开面板，再在 Dline 设置中配置模型服务商，参见[模型配置](/zh-cn/getting-started/authorizing-with-dline/)。

## 从 VSIX 文件安装

<Steps>

1. 打开 [GitHub Releases](https://github.com/TuvokYang/Dline/releases)，进入要安装的版本。

2. 在该版本的 **Assets** 中下载 `.vsix` 安装包，而不是源码压缩包。

3. 在编辑器命令面板中运行 **Extensions: Install from VSIX...**，选择下载的 `.vsix` 文件。

</Steps>

也可以在终端中执行：

```bash
code --install-extension <vsix-file>
```
