Dline ships as an editor extension and requires VS Code 1.134.0 or newer.

## Install from the extension marketplace

<Steps>

1. Press `Ctrl+Shift+X` (`Cmd+Shift+X` on macOS) to open the Extensions view.

2. Search for `Dline`.

3. Click **Install** on the Dline extension.

4. Click the Dline icon in the activity bar to open the Dline panel.

5. Configure a model provider in Dline settings. See [Authorization and model setup](/en/getting-started/authorizing-with-dline/).

</Steps>

<Aside>
Editors such as Windsurf and VSCodium use the Open VSX registry. The install flow is the same.
</Aside>

## Install from a VSIX file

After you obtain a `.vsix` file, run **Extensions: Install from VSIX...** from the Command Palette and select the file, or run the following in a terminal:

```bash
code --install-extension <vsix-file>
```
