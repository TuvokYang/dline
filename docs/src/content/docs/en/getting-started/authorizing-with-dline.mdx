Dline connects to AI models through a **provider**. You can:

- **Bring your own API key** for a cloud provider such as Anthropic, OpenAI, or OpenRouter.
- **Run models locally** with Ollama or LM Studio on your own machine, with no API key.

## Set up in VS Code

<Steps>

1. Click the **Settings** button in the Dline panel title bar to open **API Configuration**.

2. Click **Add profile** to create a Profile. If you already have one, you can expand its card with the button on the left and edit it instead.

3. Choose a provider from the **Provider** dropdown.

4. Authenticate:
   - **Cloud provider:** paste your key into the provider's key field, such as **OpenAI API Key**.
   - **Local runtime (Ollama / LM Studio):** no key is needed; make sure the runtime is running.

5. Choose an available model under **Model**.

</Steps>

![Creating a Profile in API Configuration, choosing a provider and model, then selecting the Profile in the input area](/assets/profile-setup.gif)

Each Profile combines a provider, a model, and a key. You can create several Profiles and use different ones for Act, Plan, and subagents. See [Multiple Profiles](/en/customization/profiles/).

## Choosing a provider

### Cloud providers

| Provider | Best for | Setup guide |
| --- | --- | --- |
| **OpenRouter** | Many vendors' models with one key | [Setup](/en/provider-config/openrouter/) |
| **Anthropic** | Direct Claude access | [Setup](/en/provider-config/anthropic/) |
| **Claude Code** | Claude Max/Pro subscription | [Setup](/en/provider-config/anthropic/) |
| **OpenAI** | GPT models | [Setup](/en/provider-config/openai/) |
| **Google Gemini** | Gemini models | [Setup](/en/provider-config/google-gemini/) |
| **AWS Bedrock** | Models billed through your AWS account | [Setup](/en/provider-config/aws-bedrock/api-key/) |
| **DeepSeek** | Good value | [Setup](/en/provider-config/deepseek/) |

### Local models

Run models on your own hardware: data stays on your machine and there are no per-request charges.

| Runtime | Best for | Setup guide |
| --- | --- | --- |
| **Ollama** | Command-line local runtime | [Setup](/en/running-models-locally/overview/#runtime-options) |
| **LM Studio** | GUI local runtime | [Setup](/en/running-models-locally/overview/#runtime-options) |

Local models need capable hardware, especially GPU memory. See [Running models locally](/en/running-models-locally/overview/) for requirements.

## Troubleshooting

| Issue | Fix |
| --- | --- |
| Requests return 401 or the key is rejected | Paste the key into the Profile's key field again and make sure it belongs to the selected provider. |
| The model list is empty or requests time out | Check your network and proxy settings. See [Networking and proxies](/en/troubleshooting/networking-and-proxies/). |
| Dline cannot reach a local model | Make sure Ollama or LM Studio is running and the address in settings matches the address the runtime listens on. |
