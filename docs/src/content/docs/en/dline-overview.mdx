Welcome to the Dline documentation. Whether you are just getting started or want to explore advanced capabilities, you will find what you need here.

## What is Dline?

Dline is an AI coding agent that lives in your editor. It can read and write files, run terminal commands, use a browser, and help you build features through natural-language conversation.

By default, Dline asks for your confirmation before it reads or writes files, runs commands, or calls external tools. You can enable auto-approval for low-risk operations in settings.

## Install Dline

Dline ships as a VS Code extension and requires VS Code 1.134.0 or newer. After you obtain a `.vsix` file, load it with the VS Code "Install from VSIX" command, or run the following in a terminal:

```bash
code --install-extension <vsix-file>
```
