MiniMax offers competitively priced models with large context windows, including the MiniMax-M2 series.

**Website:** [minimax.io](https://www.minimax.io/)

## Get an API key

<Steps>

1. Go to the [MiniMax Platform](https://www.minimax.io/platform) and sign up or sign in.

2. Open the API key management page.

3. Create a new API key.

4. Copy the key immediately and store it securely.

</Steps>

## Configure Dline

See [Authorization and model setup](/en/getting-started/authorizing-with-dline/) for the general flow.

<Steps>

1. Click the **Settings** button in the Dline panel title bar.

2. Set **API Provider** to **MiniMax**.

3. Paste the key into the **MiniMax API Key** field.

4. Select a model under **Model**.

</Steps>

## Tips

- **Large context:** Every built-in MiniMax-M2 series model supports a 192K-token context window.
- **Reasoning:** M2.7 and M2.5 support extended thinking for complex tasks.
- **Pricing:** See the [MiniMax pricing page](https://www.minimax.io/platform/document/pricing) for current rates.
