OpenRouter offers models from many providers through one unified API, which makes it easy to switch between and compare models.

**Website:** [openrouter.ai](https://openrouter.ai/)

## Get an API key

<Steps>

1. Go to [OpenRouter](https://openrouter.ai/) and sign in with your Google or GitHub account.

2. Open the [Keys page](https://openrouter.ai/keys) and copy an existing key or create a new one.

</Steps>

You can also click **Get OpenRouter API Key** in Dline settings. After you authorize in the browser, Dline receives the key automatically.

## Configure Dline

See [Authorization and model setup](/en/getting-started/authorizing-with-dline/) for the general flow.

<Steps>

1. Click the **Settings** button in the Dline panel title bar.

2. Set **Provider** to **OpenRouter**.

3. Paste the key into the **OpenRouter API Key** field. Once it is filled in, your account balance appears next to the field.

4. Search for and select a model under **Model**.

</Steps>

The key is stored locally and only used to make API requests from this extension.

## Tips

- **Pricing:** OpenRouter bills at the underlying model's price. See [OpenRouter Models](https://openrouter.ai/models) for details.
- **Prompt caching:** OpenRouter forwards caching requests to underlying models that support caching. See [OpenRouter Models](https://openrouter.ai/models) for which models offer it.
- **Routing:** The model information area offers provider sorting options that control which underlying providers OpenRouter routes requests to.
