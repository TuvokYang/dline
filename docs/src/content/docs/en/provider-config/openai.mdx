**Website:** [openai.com](https://openai.com/)

Dline offers two ways to use OpenAI models:

- **OpenAI**: use an OpenAI API key, billed per token.
- **ChatGPT Subscription**: sign in with a ChatGPT subscription account, with no API key to manage.

## OpenAI API key

### Get an API key

<Steps>

1. Go to the [OpenAI Platform](https://platform.openai.com/) and sign up or sign in.

2. Open the [API keys](https://platform.openai.com/api-keys) page.

3. Click **Create new secret key** and give the key a recognizable name, such as `Dline`.

4. Copy the key immediately and store it securely. OpenAI will not show it again.

</Steps>

### Configure Dline

See [Authorization and model setup](/en/getting-started/authorizing-with-dline/) for the general flow.

<Steps>

1. Click the **Settings** button in the Dline panel title bar.

2. Set **API Provider** to **OpenAI**.

3. Paste the key into the **OpenAI API Key** field.

4. Search for or select a model under **Model**.

</Steps>

The same **OpenAI** provider also connects to Azure OpenAI and other OpenAI-compatible services. See [OpenAI-compatible services](/en/provider-config/openai-compatible/).

## ChatGPT subscription

<Steps>

1. Open Dline settings and set **API Provider** to **ChatGPT Subscription**.

2. Click **Sign in**. Dline opens the **Sign in to ChatGPT** dialog and launches your system browser.

3. Authorize in the browser. When the browser returns to Dline automatically, the dialog closes and the status shows **Signed in**.

4. Select a model under **Model**. The available models depend on your ChatGPT plan.

</Steps>

### When the browser cannot return automatically

1. Keep the **Sign in to ChatGPT** dialog open. Do not cancel it.
2. Copy the **full callback URL** from the browser address bar after authorization completes.
3. Paste it into the **Full callback URL** field in the dialog, then click **Finish sign-in**.

If the browser does not open automatically, copy the sign-in URL from the dialog and paste it into a browser yourself. If the sign-in times out, click **Try again** to start over.

### Import an existing credential

If the normal sign-in cannot complete, expand **Advanced: import OAuth credential JSON** in the dialog, paste the full OAuth credential JSON, and click **Import credential**. The credential is written to that profile's own secret file.

### Multiple profiles

Each API profile stores its own ChatGPT credential. Signing in, signing out, or deleting one profile never affects another. To use several profiles, sign in once for each of them.

<Aside type="caution">
Never commit the `secrets/` files in the Dline data directory to version control, attach them to tickets, or send them to others. To switch accounts, use **Sign in again** instead of editing credential files by hand.
</Aside>
